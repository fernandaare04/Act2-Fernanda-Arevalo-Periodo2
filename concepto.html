Clase 02

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada). Es un lenguaje que se utiliza para diseñar y dar estilo a las páginas web. Con CSS es posible cambiar colores, tamaños de texto, posiciones de los elementos, fondos, bordes y muchos otros aspectos visuales.

CSS permite separar el contenido de una página (HTML) de su presentación visual. Esto hace que las páginas sean más organizadas, fáciles de mantener y visualmente más atractivas.

CSS también permite crear diseños responsivos, animaciones, efectos visuales y una mejor experiencia para el usuario al navegar en un sitio web.
